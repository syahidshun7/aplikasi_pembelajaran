CONFIG LIGHT PROFILE SKIN

Contoh skin ringan berbasis JSON config.

Cara pakai:
1. Buka Admin > PROFILE SKINS.
2. Klik Create_Import_Skin.
3. Pilih folder public/examples/profile-skin-config-light.
4. Equip skin Config Light.

Catatan:
- Skin ini tidak memakai iframe.
- Tidak ada HTML/CSS/JS project terpisah.
- Backend menyimpan config_json dari object "config" di skin.json.
- Public profile merendernya lewat Vue internal ConfigSkinRenderer.
- Cocok untuk mayoritas skin resmi agar server dan browser lebih ringan.
